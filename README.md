# Data Science & Python Portfolio — Matías Barra

Portafolio de proyectos desarrollados durante mi formación y práctica en **Data Analytics, Data Science y Machine Learning con Python**.

Mi foco está en aplicar análisis de datos y modelos predictivos a problemas que puedan traducirse en decisiones de negocio: comportamiento de clientes, segmentación, predicción, clasificación y optimización de procesos.

🌐 **Portafolio profesional:** https://kumviero.github.io/

## Proyectos destacados

### 1. Customer Churn Prediction
**Machine Learning · Clasificación · Customer Analytics**

Análisis del abandono de clientes utilizando un dataset de telecomunicaciones. El proyecto aborda preparación y exploración de datos, entrenamiento de modelos de clasificación y evaluación de desempeño para identificar patrones asociados al churn.

**Conceptos aplicados:** Python, Pandas, scikit-learn, clasificación, evaluación de modelos y análisis de clientes.

➡️ [Ver proyecto](./Machine%20Learning/Desafio%20Prediccion%20de%20chun)

### 2. Titanic — Survival Prediction
**EDA · Clasificación · Model Evaluation**

Proyecto de Data Science orientado a predecir la supervivencia de pasajeros del Titanic. Incluye análisis exploratorio, preparación de variables y comparación de modelos como regresión logística y árbol de decisión mediante métricas de clasificación.

**Conceptos aplicados:** Python, Pandas, visualización, regresión logística, árboles de decisión, accuracy, precision, recall y F1-score.

➡️ [Ver proyecto](./Data%20Science%20Titanic)

### 3. Modelos avanzados y redes neuronales
**Machine Learning avanzado · Deep Learning · Predicción**

Colección de proyectos que exploran problemas predictivos más complejos, incluyendo detección de cardiopatías, cancelación de reservas, churn y detección temprana de renuncias.

**Conceptos aplicados:** modelos ensemble, redes neuronales, clasificación, optimización y evaluación de modelos.

➡️ [Explorar proyectos](./Modelos%20avanzados%20y%20redes%20neuronales)
